# Perfiles de ejemplo

`blank.example.json` deja pendientes las medidas de un montaje nuevo. `r5-tested.example.json` conserva los parámetros medidos del R5 ensayado y sus confirmaciones parciales; no contiene identidad ni datos personales. Copia el perfil elegido a `.local/` antes de modificarlo para una unidad real.

1561 cuentas/vuelta y los signos del R5 no son valores universales. Geometría, límites, ganancias y tensión siguen pendientes: el perfil general de conducción no está habilitado. La aplicación `forward-3s` utiliza direcciones fijas comprobadas y no carga estos JSON en tiempo de ejecución.
